## 1. catr.jp（官報決算公告のまとめサイト）は承認ソースか　★最優先・全体で約825行に影響

RULES §7-1 として既に認識されている論点。検証を進めた結果、想定より広範囲に効いている。

| | 件数 |
|---|---:|
| △確認不可層（T3）で §7-1 待ちにより止まっている行 | 433行中 **181行＝41.8%** |
| T3 全1,865行への外挿 | **約780行** |

**うち93%（181行中168行）は、官報決算公告で金額を既に確認済み**である。
つまり「数字は分かっているが、その出典を認めてよいか分からない」という状態で
止まっている。調べ直しても解決しない。**先方の回答だけが解除条件。**

**「可」と回答が出れば最大約825行が一斉に架電可能になり、「不可」なら一斉に確定除外になる。**どちらでも作業は減るが、
回答が無い限りこの380行は宙に浮いたままで、リストとして使えない。

検証エージェントの所見でも「§7-1 が承認された瞬間に○へ反転する行」という記述が
繰り返し現れている（テーブルマーク1,135.28億円、酒田共同火力発電530.59億円、
大王パッケージ505.65億円、名鉄観光サービス535.80億円 ほか）。

**なぜ避けられないか**：官報のオンライン無料公開は直近90日分のみで、過去の決算公告は
遡及できない。非上場の株式会社は決算公告以外に売上高を開示していないことが多く、
自社HPにも親会社IRにも数字が存在しない。実例：

| 企業 | 状況 |

| シチズンマシナリー | 自社HPは資本金・従業員数のみ。親会社シチズン時計のIRは工作機械「事業セグメント」値 |
| 日揮触媒化成 | 日揮HD連結比10%未満で有報「主要な損益情報」にも載らない |
| 三菱電機フィナンシャルソリューションズ | 自社HPは取扱高中心。親会社2社のIRにも単体開示なし |

### 関連論点：自治体が運営する就職ポータルは「公的機関」か（実例あり）

**白河オリンパス**（行64）で実際に判断が割れた。福島県が運営する「感働！ふくしま」に
売上高572億円の記載があり、一度は §3-4③「公的機関が公表しているデータ」として
採用されたが、実体は**就職支援ポータル＝求人媒体**であり差し戻した。同じ572億円が
マイナビ2026/2027/2028・就活会議・Baseconnect にも並んでおり、自社サイトには
売上高の記載自体がない。

同型：福井県「291JOBS」（大西商事）、豊岡市「job-navi」（神戸トヨペット）、
静岡県「しずおか就職net」、新潟県「新潟企業情報ナビ」。

**確認したいこと**：運営主体が自治体であれば承認ソースとして認めるか、
それとも求人媒体としてNGか。

**確認したいこと**：官報そのものは公的情報だが catr.jp は民間の二次サイト。
これを承認ソースとして認めていただけるか。

- **認める場合** → 59行がそのまま架電可
- **認めない場合** → 59行を `△ 確認不可` に倒す（該当企業は他に開示経路がないため復活の余地なし）

## 2. 上場子会社／中間持株会社は連結値を使えるか　★20行に影響

RULES §3-3 は「子会社は単体300億以上のみOK」「ホールディングスはグループ連結300億超で可」
と定めるが、**その両方に当てはまる会社**の扱いが読み取れない。

典型例：**イオンフィナンシャルサービス**

- イオン(株)の連結子会社（＝子会社ルールなら単体が必要）
- 同時に東証プライム上場で、自ら連結決算を開示する中間持株会社（＝HDルールなら連結300億超で可）
- 単体営業収益は有報本体にしかなく、承認ソースから取得困難

同型の行：20, 53（アイフル。2026/4/1にムニノバHDの完全子会社化）, 121, 337, 429（伊藤忠食品。
伊藤忠による完全子会社化で上場廃止予定）, 629, 665, 678 ほか。

**確認したいこと**：「上場していて自ら連結財務諸表を作成・開示している会社」は、
親会社がいても連結値で判定してよいか。

## 3. 総額表示か純額表示か（遊技・小売の「売上高」）　★10行に影響

RULES §6-3 は会計基準変更による乖離を扱うが、**業界慣行として総額表示が残る業種**の
判断基準がない。

- パチンコホールの「売上高」は貸玉料総額ベースで公表されることが多い。収益認識基準の
  純額表示に直すと1桁小さくなる例がある（ダイナムJHD等）。一方マルハン等は総額で年商公表
- 実例：**ジョイパック** 1,267億円（自社公式）。純額なら200億円前後まで落ちて条件外に転落しうるが、
  官報決算公告は貸借対照表のみで純額の売上高が存在せず判別不能
- **ひぐち**（まるみつ）も同型で、単体売上高が自社HP・決算公告のいずれにも存在しない

**確認したいこと**：自社が公式に「売上高」として発信している総額値を採用してよいか。

## 4. 「売上高」以外の指標の扱い　★49行に影響

RULES §3-7 は「銀行・保険は経常収益」までは定めているが、実際にはもっと多様な指標が出てくる。

| 指標 | 出てくる業種 | 例 |
|---|---|---|
| 営業収益 | 鉄道・不動産・リース・貸金 | ダイビル、アイフル、静岡鉄道 |
| 経常収益 | 銀行 | 沖縄銀行（RULES記載済み） |
| 取扱高 | 商社・フィナンシャル | 三菱電機フィナンシャルソリューションズ、大丸興業（輸入1,290億/輸出90億の取扱高のみ公表） |
| 売上収益（IFRS） | RULES記載済み | 三井海洋開発 |
| 外貨建て | 外資系日本法人 | 三井海洋開発 4,581百万USドル（円換算値がG列に無い） |

**確認したいこと**：営業収益は売上高と同義として採用してよいか。取扱高は採用不可という理解でよいか。
外貨建ての場合の円換算レートの扱い。
